# MyEnglishbot

این یک ربات تلگرام برای یادگیری زبان انگلیسی (لغات و گرامر) است.

## پیش‌نیازها
- پایتون نسخه ۳.۸ یا بالاتر

## نحوه نصب
ابتدا کتابخانه‌های مورد نیاز را با دستور زیر نصب کنید:
pip install -r requirements.txt

## نحوه اجرا
برای روشن شدن ربات، دستور زیر را در ترمینال اجرا کنید:
python newfile12345.py
